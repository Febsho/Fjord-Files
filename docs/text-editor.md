# Textansicht und Bearbeitung

UTF-8-Dateien mit LF-Zeilenenden bis 256 KiB können in der Textansicht bearbeitet werden. Änderungen sind zunächst ungespeichert; beim Verlassen wird nachgefragt. Speichern erstellt neben der Originaldatei eine neue Datei mit `.edited` beziehungsweise einer fortlaufenden Nummer. Bestehende Dateien und symbolische Links werden nicht überschrieben. Der Tab wechselt auf die neu erzeugte Datei. Wenn die vorher gelesene Datei beim Speichern bereits andere Inhalte hat, wird das Speichern abgelehnt und der Text im Editor behalten.

Große Dateien und UTF-8-Dateien mit anderen Zeilenenden werden nur lesend als begrenzte Vorschau angezeigt. Die Ansicht hebt Schlüsselwörter, Zeichenketten, Zahlen und Kommentare für C/C++, Go, JavaScript/TypeScript, Python, Rust, Shell, JSON, YAML, TOML und XML hervor, wenn die Dateiendung erkannt wird. Bearbeitbare Dateien öffnen zunächst in der Leseansicht; die Schaltfläche „Text bearbeiten“ wechselt zum Plain-Text-Editor. Zeilennummern lassen sich in der nicht umgebrochenen Ansicht einschalten. Während eine bearbeitbare Textvorschau geöffnet ist, prüft der Dienst alle zwei Sekunden ihren Inhalts-Hash. Bei einer externen Änderung, Löschung oder Datei, die nicht mehr sicher bearbeitet werden kann, erscheint ein Hinweis. „Neu laden“ lädt den aktuellen Inhalt; bei eigenen ungespeicherten Änderungen fragt die Anwendung vorher nach. Suche funktioniert in der Lese- und Bearbeitungsansicht; Ersetzen ist im Bearbeitungsmodus verfügbar und unterscheidet Groß- und Kleinschreibung. Die Versionsprüfung verhindert kein gleichzeitiges Ändern der Quelle während des Lesens. Bei einem Schreibfehler kann eine unvollständige neue Datei zurückbleiben; ihr Pfad wird im Fehler genannt.
